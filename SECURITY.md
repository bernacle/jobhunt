# Security policy

Narrow handles sign-in, access tokens and people's career data, so we take
vulnerability reports seriously and appreciate them.

## Reporting a vulnerability

**Please don't open a public issue, pull request or discussion for a
security vulnerability.** Report it privately instead:

1. **Preferred:** GitHub private vulnerability reporting. Go to the
   repository's **Security** tab and choose **Report a vulnerability**. Only
   the maintainers can see the report.
2. **If that option isn't available yet**, open a public issue titled
   "Security contact request" that contains **no details** of the problem.
   A maintainer will reply with a private way to send the report.

Please include what you found, where (file, endpoint or command), how to
reproduce it, and the impact you expect. Don't access other people's data,
and use only accounts and data you own when testing.

We'll acknowledge the report, keep you updated while we investigate, and
credit you when the fix is published, unless you'd rather stay anonymous.

## Supported versions

Narrow has no releases yet. Fixes land on `main`.
